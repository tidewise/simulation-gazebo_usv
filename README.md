# Plugin to support vessel-related functionality in Gaezbo simulations

The plugin is meant to be added to a `<model>`. Synopsis:
```
<plugin name="gazebo_usv::Actuators" filename="gazebo_usv">
    <thrusters>...</thrusters>
    <rudders>...</rudders>
    <wave_dynamics>...</wave_dynamics>
    <wind_dynamics>...</wind_dynamics>
    <direct_force>...</direct_force>
</plugin>
```

## Thrusters

Thrusters are 'force applying' devices. To define thrusters, first define the
links whose X axis is the thrust direction, and then link them with the plugin:

```xml
<link name="thrust_defining_link">
</link>

<plugin name="gazebo_usv::Actuators" filename="gazebo_usv">
    <thrusters>
        <topic>thrusters</topic>
        <thruster name="thrust_defining_link">
            <min_thrust>...</min_thrust>
            <max_thrust>...</max_thrust>
        </thruster>
    </thrusters>
</plugin>
```

The name of the thruster is the name of the link, related to the model in which the plugin
is added. The plugin creates a topic of type `gz.gazebo_usv.Thrusters` that allows to
control all the thrusters in a given plugin block. This topic name is by default
the `thrusters` subtopic of the model's topic name (which is of the form
`/model/model_name/model/submodel_name`). By defining the `<topic>` element as child of
the `thrusters` element, the topic name will be `$BASENAME/thrusters/TOPIC_NAME`, which
allows to have more than one set of thrusters in a given model.

## Rudders

The rudders apply a force that is computed from the fluid flow velocity at the pose of
the rudder center. The flow velocity can be induced by the movement of the vessel, but
also by one thruster associated with the rudder

```xml
<link name="thruster_starboard">
</link>
<link name="rudder_starboard">
</link>

<plugin name="gazebo_usv::Actuators" filename="gazebo_usv">
    <thrusters>
        <thruster name="thruster_starboard">
            <min_thrust>...</min_thrust>
            <max_thrust>...</max_thrust>
        </thruster>
    </thrusters>

    <rudders>
        <rudder name="rudder_starboard">
            <!-- area of the rudder in m^2 -->
            <area>...</area>
            <!-- lift factor -->
            <lift_factor>...</lift_factor>
            <!-- drag factor -->
            <drag_factor>...</drag_factor>

            <!-- optional name of a thruster that will be accounted for
                 when calculating flow velocity -->
            <thrusterName>thruster_starboard</thrusterName>
            <!-- scale factor used to account for the effort generated by the
                 thruster. Flow velocity is sqrt(v|v| + thrustToFlowK * thrusterEffort)
                 -->
            <thrustToFlowK>...</thrustToFlowK>
        </rudder>
    </rudders>
</plugin>
```
